CoxRTL: recalibrated transfer learning for survival prediction

Introduction

This vignette reproduces the simulation example of the README. It evaluates transfer-learning methods for survival prediction under covariate shift. The workflow:

  1. generate simulated target, deployment and external datasets,
  2. screen the external datasets for transferability,
  3. estimate density-ratio weights for covariate-shift correction,
  4. fit multiple Cox-based models,
  5. evaluate predictive performance using Harrell’s C-index, time-dependent AUC and the Brier score.
workflow

# Covariate shift parameters
ratio_scale_TeS <- 0.5   # Shift magnitude between deployment and external datasets

4. Screen the external datasets for transferability

Borrowing information from an external dataset only helps when its predictor-outcome relationship is close enough to the target domain. detect_transferable() screens each candidate external dataset by its predictive gain in the target domain before anything is weighted or pooled. It partitions the target dataset into V folds and, within each fold, compares two penalized Cox models, both using the same alpha as the model fits below and both evaluated on the held-out target fold with Harrell’s C-index:

  • a target-only model fitted on the target fitting folds, and
  • a two-step transfer model that pools the candidate external dataset with the target fitting folds and then applies a target-based debiasing correction.

The average difference across folds is delta_C and its median is delta_C_median. Under the rule = "median" used below a dataset is declared transferable when delta_C_median exceeds threshold (0 by default), and the verdict is reported in the transferable column of the summary table, next to the gains it was derived from.

X_s_list <- lapply(data_s, function(d) as.matrix(d[, 1:p]))
y_s_list <- lapply(data_s, function(d) Surv(d$time, d$status))

screen <- detect_transferable(
  X_t = X_target, y_t = y_target,
  X_s_list = X_s_list, y_s_list = y_s_list,
  rule = "median", min_prop_positive = 0,
  alpha = alpha, V = 5, seed = 123
)
summary(screen)

5. Estimate density-ratio weights

We use the calibration subset from the deployment population as the reference distribution. calculate_weights() estimates an exponential-tilting model between the denominator dataset (the data to be reweighted) and the numerator dataset (the deployment calibration data), then truncates and normalises the resulting weights. The truncation interval is set by clip, either as the two truncation probabilities or as a single central coverage: the default clip = c(0.025, 0.975) clips at the 2.5th and 97.5th percentiles, clip = 0.95 is shorthand for the same interval.

# External-to-deployment weights
w_source <- do.call(c, lapply(1:3, function(i) {
  calculate_weights(
    X_denominator = as.matrix(data_s[[i]][, 1:p]),
    X_numerator = X_calibrate,
    cv_lambda = FALSE,
    ncore = 1
  )$w
}))

# Target-to-deployment weights
weight_target <- calculate_weights(
  X_denominator = X_target,
  X_numerator = X_calibrate,
  cv_lambda = FALSE,
  ncore = 1
)
summary(weight_target)

6. Fit survival models

Each model is fitted with a single fit_coxrtl() call (the underlying penalized-Cox and two-step transfer-learning routines are internal to the package). Two survival modelling strategies, selected by the logical argument transfer:

  • transfer = FALSE: penalized Cox model trained using only the target dataset;
  • transfer = TRUE: two-step transfer-learning model that borrows information from external datasets.

Either model can be fitted without weights, in which case it is not calibrated for covariate shift, or with the density-ratio weights, in which case it is recalibrated toward the deployment population. The target-only model consumes the target weights w_t alone; the transfer model consumes w_t and the external weights w_s. Both forms of both models are fitted below.

Requesting coefficient-level confidence intervals through bootstrap = TRUE makes fit_coxrtl() return list(beta, ci) instead of a bare coefficient vector. Under the hood nboot nonparametric resamples of the subjects are drawn and the model is refitted at the full-data lambda on each resample. The resampling is seeded via the seed argument, and when ncore > 1 the parallelisation acts across resamples rather than inside the cross-validation:

Target-only model: transfer = FALSE

The target-only model uses the target dataset only, so X_s and y_s are not supplied at all.

nontransfer_unw <- fit_coxrtl(
  X_t = X_target, y_t = y_target,
  transfer = FALSE, alpha = alpha, lambda = lambda,
  type.measure = "deviance", seed = 123,
  bootstrap = TRUE, nboot = 100
)

Target-only model, reweighted: transfer = FALSE with w_t

nontransfer_w <- fit_coxrtl(
  X_t = X_target, y_t = y_target,
  w_t = w_target,
  transfer = FALSE, alpha = alpha, lambda = lambda,
  type.measure = "deviance", seed = 123,
  bootstrap = TRUE, nboot = 100
)

Transfer model: transfer = TRUE

transfer_unw <- fit_coxrtl(
  X_t = X_target, X_s = X_s_all, y_t = y_target, y_s = y_s_all,
  transfer = TRUE, alpha1 = alpha, alpha2 = alpha, lambda = lambda,
  type.measure = "deviance", seed = 123,
  bootstrap = TRUE, nboot = 100
)

All models are evaluated on the held-out evaluation subset from the deployment population.

7.3 Brier score

The Brier score is evaluated at 100 time points spanning the event times in the evaluation set (as in the README), and reported as the integrated error (ierror).

preds_train <- predict_coxrtl(X = X_target, transfer_w)$pred

# Evaluation time points
times <- c(0.77, 1.47, 2.20, 2.93)

# Calculate Brier scores
briers <- predErr <- survAUC::predErr(
    Surv.rsp = Surv(
      data_target$time,
      data_target$status
    ),
    Surv.rsp.new = Surv(
      data_evaldata$time,
      data_evaldata$status
    ),
    lp = as.matrix(preds_train),
    lpnew = as.matrix(preds),
    times = times,
    type = "brier",
    int.type = "weighted"
  )
